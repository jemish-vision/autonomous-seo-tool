# Migration Brief — Next.js → Vite React + Express (Supabase-only)

Single source of truth for anyone (human or agent) working on this port. **Read fully before editing.**

## Goal

Rebuild `autonomous-seo-platform/poc/seo-dashboard` (Next.js 16) as two independent npm projects:

- `server/` — Express + Prisma + Supabase. **Data source = Supabase Postgres + Storage ONLY. No filesystem.**
- `client/` — Vite + React 19 + Tailwind v4. Talks to the Express API. Supabase used for **auth only**.

**Behaviour and visual design must match the old app.** Same pages, same components, same CSS.

## Component port rules (MECHANICAL — apply uniformly)

Every file under `client/src/components/**` was copied verbatim from Next.js. Transform:

1. `"use client";` first line → **delete it** (Vite has no such concept).
2. `import Link from "next/link"` → `import { Link } from "react-router-dom"`. Then `<Link href=...>` → `<Link to=...>`.
3. `import { usePathname, useSearchParams, useRouter } from "next/navigation"` → `react-router-dom`:
   - `usePathname()` → `useLocation().pathname`
   - `useSearchParams()` → react-router's `useSearchParams()` returns `[params]` (URLSearchParams) — `.get()` works the same.
   - `useRouter()` → `useNavigate()`; `router.push(x)` → `navigate(x)`; `router.replace(x)` → `navigate(x,{replace:true})`; **drop** `router.refresh()`.
4. `import Image from "next/image"` → plain `<img>` (drop `next/image`; keep width/height/alt/className; `fill` → className `absolute inset-0 h-full w-full object-cover`).
5. `next/font` — none inside components (handled in index.html/globals). If found, delete.
6. Any import from a **server-only** old lib (`@/lib/data`, `@/lib/data-*`, `@/lib/auth-server`, `@/lib/crawl-*`, `@/lib/db-loader`, `@/lib/gsc/*` server files, `@/lib/mutes` if server, `@/lib/events-log`) must NOT be pulled into the client. Options:
   - If it's a **type** import → point at `@/lib/data` (client type shim) or `@/lib/types`, adding the type there if missing.
   - If it's **data fetching** → replace with the matching `@/api/*` hook.
7. Keep all Tailwind classes and JSX exactly — **do not restyle**. Design must stay pixel-identical.
8. `<a href="/x">` used for in-app nav → `<Link to="/x">` (keep real external `<a>` as-is).

## Backend module rules

- Reuse the vendored query layer (`server/src/db/src/**`) — it already reads Supabase. Import functions from `db/src/crawl/readStore.js`, `db/src/gsc/store.js`, etc. (note the `.js` extension — this is ESM).
- One `modules/<domain>/<domain>.routes.ts` exporting a `Router`. Mount in `app.ts` under `requireAuth`.
- Match the old `app/api/**` paths so the client hooks line up.
- Where no vendored fn exists, write a small Prisma query against `prisma` (from `db/prisma.js`). Keep it readable.
- No `node:fs` data reads. Blobs (screenshots, raw HTML, exports) → Supabase Storage signed URLs via `mintSignedUrl`.

## Parity gaps (known, documented — do NOT silently fake data)

The current sync writes a lossy projection. These render "Not captured" / empty on Supabase-only until the sync is extended (separate task): page `headMeta`, `favicons`, `structure`, `fonts`, `charset`, `headBoundary`, `baseHref`; video poster/mime/provider; structuredData parseError; screenshots + raw-HTML replay; AI recommendations, automation report, fix plan; issue `threshold`/`scope`/`categories`/`grade`. See root README "Parity gaps". Leave the panels; they already handle absence gracefully.
